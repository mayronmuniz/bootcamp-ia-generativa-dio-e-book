📚 E-book Interativo: IA Generativa (Flipbook Edition)

Desafio de Projeto - Bootcamp Fundamentos de IA Generativa - DIO

📜 Sobre o Projeto

Este repositório hospeda um E-book Dinâmico e Interativo desenvolvido durante o Bootcamp Fundamentos de Inteligência Artificial Generativa, da DIO em parceria com o Santander Universia.

Diferente de arquivos PDF estáticos e tradicionais, este projeto utiliza tecnologias Web para criar uma experiência de leitura imersiva, simulando a sensação física de folhear um livro real (efeito Page Flip).

O conteúdo do livro é composto por uma história infantil estilo paradidático com áudio de narração e imagens coloridas.

🎯 O Desafio

O objetivo foi criar uma aplicação web que servisse como plataforma de distribuição de conhecimento, integrando:

Conteúdo Rico: Textos e imagens gerados ou curados com auxílio de IAs Generativas.

UX Diferenciada: Uma interface que foge da rolagem vertical padrão, oferecendo navegação por "virada de página" (Flip).

Acessibilidade & Responsividade: Funcional em desktops, tablets e smartphones.

🎮 Funcionalidades

Efeito Flip 3D: Transições suaves que imitam o comportamento físico do papel ao navegar entre as páginas.

Zoom Interativo: Permite aproximar detalhes de textos e diagramas sem perda de qualidade.

Modo Tela Cheia: Leitura imersiva sem distrações do navegador.

Miniaturas (Thumbnails): Navegação rápida visualizando todas as páginas em grade.

Pesquisa Interna: Busca textual rápida dentro do conteúdo do e-book.

Som de Página: Feedback auditivo sutil ao virar as páginas (opcional).

🛠️ Tecnologias Utilizadas

HTML5 & CSS3: Estruturação semântica e estilização do layout e responsividade.

JavaScript (ES6+): Lógica de controle da interface e carregamento dinâmico.

jQuery: Manipulação simplificada do DOM e eventos.

FlipBook Plugins: Bibliotecas especializadas para renderização do efeito de virada de página e renderização de PDF/Imagens em Canvas.

IA Generativa: Utilizada para geração de textos, resumos e ilustrações conceituais presentes no livro.

📂 Estrutura de Arquivos

/files: Contém as páginas renderizadas (imagens/HTML), configurações de busca e ativos visuais.

/javascript: Scripts principais, incluindo main_preview.js, pdf.js e plugins de flip.

/style: Folhas de estilo para o player, template e adaptações móveis.

index.html: Ponto de entrada da aplicação.
